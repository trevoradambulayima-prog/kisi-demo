# Kisi — démonstration

Version de démonstration de Kisi, une application pour trouver un médicament dans les pharmacies de Kinshasa, commander et se faire livrer.

Les données sont des exemples et restent dans le navigateur de chaque personne qui teste.

Comptes de test : indicatif +243, mot de passe `kisi1234` — client 800000301, pharmacie 800000101, livreur 800000201. Administrateur : lien « Administration », code `KISI-ADMIN`.
